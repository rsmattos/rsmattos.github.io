Newton-X is a software initially developed by [Mario Barbatti](https://barbatti.org/). It was released to the public in the year 2007[[1](#references)] and is still being continuously updated to this day.[[2](#references)] It is primarily a software for nonadiabatic dynamics, but has also found use for spectrum generation, since this important step in the preparation of the dynamics has an application in itself.

In excited state calculations we are interested to see how a molecule reacts when it is exposed to light. This can have application for identifying the material being studies, since which light it absorbs and how much can be used to identify said material. It can also have an application that is dependent on this interaction with light. One of the most relevant example of this are solar panels, materials capable of absorbing sun light and converting it into electricity that can be used to power the device you are using to read this.

Among the may techniques for studying those systems, the nonadiabatic dynamics are used to investigate what happens as time passes when such an interaction between matter and light happens. In most cases, we are interested in seeing how long it takes for the system to relax back to the state of lowest energy, if it can become something else in this relaxation and how this process happens, opening ways for us to control it.

Newton-X was create to perform those dynamics. The package contains programs capable of taking the molecule in its most likely geometry and generate many variations of it. This is because the real system won't be frozen in space, as it interacts with it's environment and just by existing, it has a certain amount of energy in the form of movements. It vibrates around the geometry of the lowest energy.

Those multiple geometries that represent the natural vibration of the molecules can also be used to generate a more accurate spectrum of it. In the spectrum, we plot the energy of the photon absorbed by the molecule vs the intensity of the absorption, and this can be used to identify the molecule. An example for this type of plot is presented below.

![Example of spectrum](assets/img/posts/2025-09-16/abs_spec_nx2007.png)  
**Figure:** Absorption spectrum of the pyrazine cation to exemplify this type of plot. Taken from [[1](#references)].

From this, we can select the energy we would use to excite the system, usually around the peak of the absorption spectrum, and ask the program to select the geometries that absorbed in that energy. This is what is called the initial condition generation. The program creates a set of geometries and velocities of the molecule for the initial time of the dynamics. For each pair of geometry and velocity we have one initial condition and we can start to propagate a single trajectory.

In the method used in Newton-X, Fewest Switches Surface Hopping ([FSSH](https://en.wikipedia.org/wiki/Surface_hopping)), we need a lot of geometries, in the order of 100, to be able to extract the properties of the simulation. To propagate the molecule in time the program has interfaces to multiple softwares capable of performing a single point calculation: given a specific geometry it computes the energies and forces of the electrons. With the forces provided by the external program the molecule is capable of moving in time. Gathering this for a hundred trajectories we can see how the real molecule behaves and this knowledge can be used to create new products and technology.

Newton-X provides the tools for doing the simulation and also for analyzing the result at the end. It is a program developed for almost 20 years with the contribution of dozens of developers, and is currently managed by me in the Light & Molecules group, in collaboration with the Professor Mario Barbatti.

More information in the website [Newton-X](https://newtonx.org/)
